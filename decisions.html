-- before get's operands

Decide before ruling 11's work startsAffects how the port reads --; found in the reference

Ruling 11 has the port model --. Measured on the reference's own binary at dfc793c4:

  • djinterp get plugin_path prints the setting.
  • djinterp get -- plugin_path answers get: the following argument was not expected: plugin_path.
  • djinterp set -- NAME=VALUE and djinterp describe -- DJIN take their operands after --.

So get alone refuses what follows --. It looks unintended, and docs/FOR_THE_LANES.md reports it. The question is what the port does meanwhile.

A cut that would part a surrogate pair

Decide before a page shows a cut valueAffects get's cuts at 511 and 1,023, and describe's shortened help

Under ruling 3 a limit counts UTF-16 units. A character outside the first plane, such as an emoji, is two units, and a cut can fall between them. What's left is half a character: text that isn't valid, which a browser shows as a replacement mark and which can't be written to a UTF-8 file as it is. The reference has the same trouble in its own unit, since it cuts bytes in the middle of a character.
